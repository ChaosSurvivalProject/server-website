### FLPR-31 论坛：头像上传功能（P2）

- `users` 表新增 `avatar` 列（相对 URL，默认空串），沿用存量表幂等补列迁移；`GET /api/auth/me` 同步返回 `avatar`。
- 新增 `POST /api/auth/avatar`（需登录）：复用 `save_image()`，单张 ≤ 2MB、仅 jpg/png/webp，中心裁剪到 256×256；覆盖上传删除旧文件，不留孤儿。
- `_author_brief()` 改为读真实 `user.avatar`，后台 `_dump_user()` 补 `avatar`；契约同步前端与 `admin-frontend` 的 API 层。
- 评论区、作者卡、导航栏用户卡等展示真实头像，加载失败回退现有默认头像；后台用户管理可查看并「重置为默认」。

### FLPR-34 论坛：用户个人主页

- 新增公开路由 `/forum/user/:id`（`UserProfile.vue`）：昵称、徽章、注册时间与发帖/获赞统计；「TA 的帖子」分页卡片列表（仅 status=1，含置顶/精华标记）与「TA 的评论」分页列表（所在帖子标题 + 纯文本评论摘要，点击跳文章）。
- 新增公开接口 `GET /api/forum/users/{user_id}/comments`（分页）：只聚合 status=1 文章下 status=1 评论，不下发任何隐私字段，与 `users/{id}/stats` 同口径。
- 评论区与文章页作者名、`AuthorCard.vue` 增加「查看主页」入口；站内信卡片跳转语义不变。
- 未登录可完整浏览；下架/驳回/回收站帖与已删评论不出现在任何 Tab；用户不存在或已注销给明确空态；移动端单列布局。

### FLPR-36 论坛：等级 / 头衔系统

- 新增两张表（不动 `users`）：`forum_user_levels`（等级/名称/所需经验，首版阈值常量化）与 `forum_user_titles`（用户、头衔 code、来源、授予/撤销时间与操作人，手动头衔留痕）。
- 经验规则首版常量化：发帖过审 +10、单帖被赞 +2、评论被赞 +1、每日登录 +1（封顶）；经验只增不减、不降级，存量用户不做历史补算，从上线起算。
- `author.badge` 由单值字符串改为**数组**（如 `["管理员", "Lv.3"]`），契约已同步 `docs/api-reference.md`；`forumBadges.js`（前台）与 `forumBadges.ts`（后台）扩表等级徽章与特殊头衔色板，改动收敛在徽章渲染组件。
- 后台用户管理新增「头衔」授予/撤销操作，前台作者卡实时生效；`role=admin` 仍出「管理员」徽章，展示不回退。
- 新增 `backend/app/forum_exp.py` 承载经验写入点（发帖过审、两个点赞 toggle、每日登录）。
