### FLPR-62 先让爬虫进门（P0）

- 新增 `frontend/public/robots.txt` 与 `frontend/public/sitemap.xml`：搜索与分享抓取全放行，`/admin/`、`/api/`、登录注册页屏蔽，sitemap 只覆盖公开规范 URL。
- 补齐 OG meta 与分享封面（`frontend/public/og-cover.png`、`shareMeta.js`），恢复 QQ / 微信 / 微博等分享链接预览卡片；Wiki 侧同步 head 配置。
- 该工单为 SEO 系列的阻断前置项：边缘网关 / WAF / CDN 仍需按反向 DNS 验证放行真实爬虫 UA（含 `Baiduspider-render` 对静态资源的抓取），robots.txt 只是声明、不是墙。

### FLPR-63 页面静态化（P1）

- 主站构建切换为 `vite-ssg build`（`ViteSSG` 入口 + 导出 `routes` / `routerOptions`），首页、阵营介绍、加入方式、资源中心、公告、服务状态等公开路由在构建期输出静态 HTML，正文、阵营名与服务器地址直接进入源码。
- 新增 `seoHead.js` 在构建期按路由写入独立 `title` / `description` / `canonical` / OG 标签；新增 `frontend/public/404.html`，不存在的路径返回真 404，不再 fallback 到首页。
- Wiki 新增进服指南、版本支持、公告归档、服务状态等可索引落地页，首页以真实 `<a href>` 链接过去；登录态与动态名单保留浏览器端获取，不阻塞预渲染。
- Nginx 规则同步：`web/nginx.conf` 与 `for-deploy/xqly-app.conf` 的 `try_files` 改为 `$uri $uri.html $uri/index.html /index.html`，避免内页统一回退到首页 HTML 导致预渲染白做。

### FLPR-64 内容与结构化数据（P2）

- 每页独立 head 补充品类后缀与长尾词；新增 `WebSite` / `SearchAction` 与加入方式 `FAQPage` JSON-LD；按路由注入 OG / Twitter 卡片信息。
- 首页撤下过期内测横幅，补齐 Java 与基岩并列的进服步骤，首屏改用 mcstatus 实时在线人数 / 版本数据（缺失显示占位符，不自造数字），页脚署名统一。
- `sitemap.xml` 覆盖全部公开 200 URL，并按源文件真实提交时间写 `lastmod`，不含后台与接口路径。

### FLPR-66 AI 答案引擎可见性与 robots.txt 策略（P4）

- `robots.txt` 显式声明检索/引用类 UA（`OAI-SearchBot`、`ChatGPT-User`、`PerplexityBot`、`Claude-SearchBot` 等）放行，训练类 UA（`GPTBot`、`ClaudeBot`、`Google-Extended`、`CCBot`）拒绝；两类开关独立，屏蔽训练类不影响搜索排名与 AI Overviews 资格。
- 补充运维信息收口说明：`docs/deployment.md`、`web/nginx.conf`、`for-deploy/xqly-app.conf` 明确后台路径、备份文件名、部署命令不得进入索引或公开页面；`Bytespider` 等无视 robots.txt 的 UA 需在 CDN / WAF 层连接级拒绝，并每季度复审清单。

### FLPR-32 站内信实时推送（SSE）

- 新增 `GET /api/messages/stream`（SSE，登录态鉴权，token 经 query 传递）：`unread` 携带最新未读数、`refresh` 提示重拉当前列表，心跳保活 ≤30s，断线由 `EventSource` 自动重连并以服务端计数为准；每用户最多 5 条连接，超出优雅关闭最旧连接。
- 服务端在回复 / 点赞 / 审核 / 系统公告 / 后台定向消息等各类 `create_*_message` 成功后向目标用户活跃连接推送；补合并提交 `de6aa33` 覆盖后台创建 / 编辑 / 删除站内信场景。
- 前端 `NavBar.vue` 轮询替换为 SSE，连续失败才降级回 60s 轮询并停止重试风暴；`Messages.vue` 监听 `refresh` 重拉当前 tab。
- 该接口是继 `POST /api/kb/chat` 之后第二个不走 `{code, message, data}` 包络的例外，已同步 `docs/agents/api-conventions.md` 与 `docs/api-reference.md`；nginx SSE 四件套在 `web/nginx.conf` 与 `for-deploy/xqly-app.conf` 两份配置中同步落地。

## 升级与发布提示

- **无数据库结构变更**：本次均为代码、静态资源与配置改动，不需要执行幂等补列 / 建表迁移。
- **新接口**：`GET /api/messages/stream` 为 SSE 包络例外，需登录 token；连接注册表为进程内实现，生产单 worker 可用，多 worker 前必须换共享存储（与限流共享存储同一条遗留）。
- **前端构建产物变化**：`npm run build` 改为 `vite-ssg build`，产物为扁平 `.html` + `404.html`；部署时 nginx / 1panel 的 `try_files` 必须包含 `$uri.html` 与 `$uri/index.html`，否则内页会回退首页 HTML。1panel 改站点设置会重新生成 nginx conf、丢手工补的 `include proxy/*.conf` 与 SSE 四件套，改完必须回服务器核对并回拷 `for-deploy/` 留档。
- **爬虫放行**：`/robots.txt` 须对任意 UA 返回 200 + `text/plain`，边缘策略需放行经反查 DNS 验证的真实爬虫与分享抓取 UA；`robots.txt` 的 `Disallow` 不等于不可索引，敏感运维信息应在服务端层面不公开。
- **镜像构建**：`.github/workflows/release-images.yml` 仅在 **GitHub Release published** 时构建并推送 GHCR，仅推送 git tag 不会触发构建；如需发布镜像，请在 GitHub 上基于 `v1.1.4` 创建并发布 Release。
- **已知提醒**：HTTPS 通配符证书 2026-12-24 到期，需提前续期。
