# 服务器规则

## 基本准则

1. **不恶意破坏** — 允许无规则生存，但禁止故意破坏他人建筑（基岩保护除外）
2. **不作弊** — 使用任何第三方客户端修改游戏数据将被封禁
3. **不刷屏** — 聊天频道禁止刷屏、广告、人身攻击
4. **尊重他人** — 无论现实身份，尊重每一位玩家

## 反作弊

- 使用 **GrimAC** 反作弊插件，检测修改游戏数据的客户端
- 使用 **CoreProtect** 记录所有玩家操作，支持回滚破坏行为

## 违规处罚

| 违规行为 | 处罚 |
|----------|------|
| 首次轻微违规 | 警告 |
| 恶意破坏 | 回滚 + 禁言 7 天 |
| 使用作弊客户端 | 永久封禁 |
| 广告/刷屏 | 禁言 3 天 |

> ⚠️ 以上规则最终解释权归星穹旅驿管理团队所有。
