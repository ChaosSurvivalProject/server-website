# 插件列表

服务器运行于 **Paper 1.21.11** 核心，搭配多种插件提供丰富玩法。

## 核心插件

| 插件 | 说明 |
|------|------|
| **Paper** | 高性能服务端核心，支持异步加载 |
| **Geyser** | 实现 Java ↔ 基岩多端互通 |
| **Velocity** | 代理层，实现多服分流 |
| **GrimAC** | 反作弊插件，检测恶意修改 |
| **CoreProtect** | 记录玩家操作，支持回滚 |

## 玩法插件

| 插件 | 说明 |
|------|------|
| **经济插件** | 玩家交易、商店、税收系统 |
| **地皮插件** | 玩家可购买领地，建造私人基地 |
| **RPG 插件** | 职业系统、技能树、任务系统 |
| **活动插件** | Boss 挑战、副本、节日活动 |
