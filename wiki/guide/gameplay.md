# 玩法指南

## 新手流程

### 1. 下载启动器

下载并安装 [PCL](https://pcl.ruanmao.net/) 或其他 Java 版 Minecraft 启动器。

### 2. 安装游戏版本

选择版本 `1.21.1 ~ 1.21.11` 下载安装。

### 3. 添加服务器

| 项目 | 详情 |
|------|------|
| 服务器地址 | `play.simpfun.cn` |
| 端口 | `37298` |

### 4. 开始游戏

启动 Minecraft → 多人游戏 → 添加服务器 → 连接

## 💡 新手建议

- **先收集资源** — 木头 → 石头 → 铁，制作基础工具
- **远离主城** — 无规则服务器主城通常是战争区域
- **建地下基地** — 挖 3 格深，建隐蔽入口
- **加入社区** — 加 QQ 群 (942235691) 与其他玩家交流

## ⚠️ 重要提醒

> 本服务器为无规则乱世生存，**不保证玩家财产安全**。
> 建议将贵重物品存放在隐蔽地点，或使用插件提供的存储功能。
