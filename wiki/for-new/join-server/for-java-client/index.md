# Java版玩家加入服务器指南
::: tip
服务器核心版本为Purpur 1.21.11，安装了ViaVersion插件，支持1.21.1~1.21.11版本游玩；
:::

## 第一步 下载客户端
### 正版登录
前往MC官网购买游戏并下载启动器，官网地址：[欢迎来到 Minecraft 官方网站 | Minecraft](https://www.minecraft.net/)
### 离线登录
通过第三方启动器下载并启动，推荐使用PCL2启动器，参考文档：[PCL2启动器下载_龙腾猫跃 - 爱发电官网](https://afdian.net/item?plan_id=86122222221212)

## 第二步 加入游戏
1. 打开启动器，选择 **1.21.10版本** 并安装游戏（以PCL2为例，按照启动器内下载指引操作）：

   <img src="/doc-image/image-LXMs.png" alt="img" style="zoom:67%;" />

2. 启动游戏，进入主界面后，点击 **多人游戏**：

   ![img](/doc-image/image-SzOn.png)

3. 进入服务器选择界面，点击 **添加服务器** 按钮：

   <img src="/doc-image/image-vhIf.png" alt="img" style="zoom:67%;" />

4. 输入服务器地址：`serverone.codeyun.com:12000`，点击 **完成**：

   <img src="/doc-image/image-gvDq.png" alt="img" style="zoom:67%;" />

5. 选中新添加的服务器，点击左下角 **加入服务器** 按钮，即可进入服务器：

   <img src="/doc-image/image-mdzS.png" alt="img" style="zoom:67%;" />

## 第三步 开始快乐的玩耍吧
### 注册与登录
- 新用户注册：输入指令 `/register 你的密码 重复你的密码`（需两次输入相同密码完成注册）。

- 已有账号登录：输入指令 `/login 你的密码` 即可登录。

  <img src="/doc-image/image-dAvv.png" alt="img" style="zoom:67%;" />

### 服务器相关信息
- 客户端版本要求：`1.21.1~1.21.10`
- 特色功能：
  - 领地系统，输入`/dom`了解指令用法
  - 箱子商店系统，输入`/qs`了解指令用法
  - 全球市场系统，输入`/ah`打开gui
  - 技能系统，输入`/mcmmo`了解指令用法
