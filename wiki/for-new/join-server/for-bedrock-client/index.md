# 基岩版玩家加入服务器指南
::: warning 游玩须知
服务器为Java版，所有特性都基于Java版，基岩版在游玩过程中可能会遇到一些BUG。如果遇到问题，欢迎向技术组负责人`@cc850`及时反馈。
:::

## 第一步 下载客户端
前往[基岩版客户端下载页面](https://xz.klpz.net/)下载并安装基岩版客户端，选择最新的正式版（目前为`1.21.132.1`）进行安装。

## 第二步 注册账号
参考视频教程：[https://www.bilibili.com/video/BV13S4y177Fc](https://www.bilibili.com/video/BV13S4y177Fc)，注册账号并登录。

## 第三步 加入游戏

启动基岩版客户端，进入游戏主界面：

  <img src="/doc-image/image-20260131092408719.png" alt="image-20260131092408719" style="zoom:67%;" />

进入`游戏`→`服务器`，点击`添加服务器`：

  <img src="/doc-image/image-20260131092518540.png" alt="image-20260131092518540" style="zoom:67%;" />


正确输入`服务器地址`和`端口`，`服务器名称`可自定义，点击`添加服务器`：

> 服务器名称：星穹旅驿纯净互通
>
> 服务器地址：serverone.codeyun.com
> 
> 端口：12000

  <img src="/doc-image/image-20260131092835085.png" alt="image-20260131092835085" style="zoom:67%;" />



## 第四步 开始快乐的玩耍吧

- 新用户注册：输入指令 `/register <你的密码> <重复你的密码>`（需两次输入相同密码完成注册）。
- 已有账号登录：输入指令 `/login <你的密码>` 即可登录。
