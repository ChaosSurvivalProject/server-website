## 星穹界的故事

这里曾经不叫乱世。

星穹界由**星穹议会**维持昼夜平衡——星穹核心悬于天际，一半燃着，一半熄着，日升月落，从不失序。人们种田、建城、通商，把这一切当作理所当然。

然后，星穹核心碎了。

没人说清那晚发生了什么。只知道天际那道裂痕撕开的瞬间，昼夜的秩序一起崩了：**长夜与残阳交替**，白天短得像喘息，黑夜长得像纪元。旧有的墙倒了，规则也倒了。

这就是**乱世**。

核心碎裂后，幸存的人分成了两派。他们对同一件事得出了完全相反的结论，于是有了这两面旗——**黎明誓约** 与 **暮夜同盟**。

> 这不是善恶对立，而是两套活法的对撞：双方都不是"好人"，也都不是"坏人"——他们都认为自己在乱世里做出了唯一正确的选择。

## 黎明誓约

> **"火种不灭，黎明必至。"**

| 项目 | 设定 |
| --- | --- |
| 核心理念 | 秩序、守护、契约、重建 |
| 代表色 | 白、金、蓝 |
| 旗帜 | 初升太阳 + 城墙 |
| 主城 | 曙光城 / 黎明堡（石砖城堡、灯塔、农田、防御墙） |
| 玩法倾向 | 防守、建设、贸易、护送、团队 PVP |
| 聊天前缀 | `[黎明]` |

大崩裂后，一群工匠、农夫、守夜人和流浪者在残破的城墙下建立了避难所。他们点燃了废墟里最后一簇火种，并立下誓约：**不弃同伴、不毁家园、不向长夜低头。**

他们认定：在乱世中，只有抱团、守约、建城，文明才不会彻底熄灭。他们要收集**黎明碎片**、点亮三座**曙光灯塔**、驱散长夜净化乱世生物，一步步把安全区的边界往外推。

**组织架构**：灯塔议会（决策层）、守夜人（防御、巡逻、阵营战）、工匠团（建筑、红石、装备、后勤）、远征队（探索、采集、遗迹攻坚）。

**弱点**：规矩多、决策慢、对叛徒容忍度低——这些在和平年代是美德，在乱世里就是破口，容易被暮夜同盟的游击战一点点消耗掉。

## 暮夜同盟

> **"长夜将至，强者为尊。"**

| 项目 | 设定 |
| --- | --- |
| 核心理念 | 自由、生存、强者为尊、长夜庇护 |
| 代表色 | 黑、红、紫 |
| 旗帜 | 残月 + 利刃 / 狼头 |
| 主城 | 永夜营地 / 暗月堡（黑石、营地、废墟、地堡、图腾） |
| 玩法倾向 | 游击、偷袭、掠夺、垄断资源、自由 PVP |
| 聊天前缀 | `[暮夜]` |

成员大多是被黎明放逐的人、长夜中活下来的流民、佣兵和掠夺者。他们在暗月下结盟，信奉"长夜不是灾难，是自由"——乱世不是惩罚，而是重新洗牌的机会。他们要在永夜中建立自己的秩序：不是没有规则，而是**规则由强者制定**。

**组织架构**：暗月议会（松散决策，各队伍自治）、影刃（刺客、偷袭、情报）、荒潮（掠夺、游击、破坏）、黑市（交易、销赃、雇佣兵中介）。

**弱点**：内部分裂、信任度低、资源不稳定——没有强约束就没有强后勤，打赢了容易分赃不均，打输了各奔东西。

## 该选哪个阵营？

| 如果你喜欢…… | 你可能属于 |
| --- | --- |
| 建设家园、抱团发展、稳定后勤、正面团战 | 黎明誓约 |
| 自由游猎、游击偷袭、以战养战、规则由强者书写 | 暮夜同盟 |

两个阵营在设计上**镜像对立**：同一段时间双方各有主场（昼夜增益），核心资源与积分来源完全不同，任何一方的胜利都不是永久的——详细机制见[阵营对抗机制](/for-new/factions/mechanics)。
