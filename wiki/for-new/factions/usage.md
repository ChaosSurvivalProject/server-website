# 阵营玩法使用指南

本页介绍阵营系统的具体操作。阵营功能基于 **ImprovedFactions** 提供指令体系，并由 **KaMenu** 提供图形菜单。你可以任选一种方式操作：

- **图形菜单（推荐）**：输入 `/fmenu` 打开「阵营中心」，点按钮完成绝大部分操作；
- **直接输入指令**：主指令为 `/factions`，可简写 `/f`（`/fac`、`/faction` 亦可）。

::: tip 还没加入阵营？
阵营玩法目前处于内测阶段，请先通过[服务器官网](http://156.254.7.56:23333/faction-beta)申请内测资格。玩法设定与世界观见[阵营玩法总览](/for-new/factions/)。
:::

## 方式一：图形菜单

### 打开「阵营中心」

输入 **`/fmenu`**，即可打开阵营中心主菜单。菜单会根据你的阵营状态自动变化：

- **尚未加入阵营**：显示「你还没有加入任何阵营」提示，以及 [加入/创建阵营] 入口；
- **已加入阵营**：顶部显示你的阵营名、阵营主人、你的职位、当前阵营点数。

### 阵营中心功能一览

| 菜单按钮 | 功能 | 可见 / 所需职位 | 等效指令 |
| --- | --- | --- | --- |
| 成员管理 | 邀请、踢出、封禁、转让所有权 | 已加入阵营（部分操作限 Admin+ / Owner） | 见成员管理 |
| 邀请管理 | 查看、接受、拒绝收到的邀请；也可邀请他人 | 所有人 | 见邀请管理 |
| 职位管理 | 查看、创建、任命、删除职位 | Owner / Admin | 见职位管理 |
| 领地管理 | 认领 / 放弃区块、区块地图、点数查询、荒野传送 | 已加入阵营 | 见领地管理 |
| 阵营基地 | 设置 / 传送阵营公共基地 | 已加入阵营 | 见阵营基地 |
| 外交关系 | 结盟、宣战、查看外交 | Owner / Admin | 见外交关系 |
| 点数查询 | 在聊天栏查看点数与积累详情 | 已加入阵营 | `/f power` |
| 加入/创建阵营 | 查看阵营列表，创建或加入阵营 | 未加入阵营 | 见加入 / 创建阵营 |

菜单中的输入操作（如填写阵营名、玩家名）会弹出聊天栏输入框，按提示输入内容后回车，再点击对应按钮执行即可。点击各子菜单的 [返回] 可回到阵营中心。

### 加入 / 创建阵营

未加入阵营时可使用本菜单：

| 按钮 | 作用 | 等效指令 |
| --- | --- | --- |
| 查看阵营列表 | 在聊天栏查看服务器全部阵营 | `/f list` |
| 查看收到的邀请 | 查看其他阵营发来的邀请 | `/f invites` |
| 创建阵营 | 以输入框中的名字创建新阵营，你将成为 Owner | `/f create <阵营名>` |
| 加入阵营 | 申请加入输入框中的阵营 | `/f join <阵营名>` |

::: warning 阵营名规则
阵营名支持**任意字符**（含中文），最长 36 个字符。**公开阵营**可直接加入；**仅邀请阵营**需要先获得该阵营的邀请，再前往邀请管理接受。
:::

### 邀请管理

| 按钮 | 作用 | 等效指令 |
| --- | --- | --- |
| 查看收到的邀请 | 在聊天栏查看邀请列表 | `/f invites` |
| 接受邀请 | 接受输入框中阵营的邀请，正式加入 | `/f inviteaccept <阵营名>` |
| 拒绝邀请 | 拒绝输入框中阵营的邀请 | `/f invitediscard <阵营名>` |
| 邀请玩家加入 | （已加入阵营）邀请输入框中的玩家 | `/f invite <玩家名>` |

### 成员管理

已加入阵营后可用。在输入框填写目标玩家名，再点击按钮：

| 按钮 | 作用 | 所需职位 | 等效指令 |
| --- | --- | --- | --- |
| 查看成员列表 | 查看全部成员与在线状态 | 成员 | `/f members` |
| 邀请玩家 | 向目标玩家发出加入邀请 | 成员 | `/f invite <玩家名>` |
| 踢出成员 | 将目标玩家移出阵营 | Admin 及以上 | `/f kick <玩家名>` |
| 封禁玩家 | 禁止目标玩家加入本阵营 | Admin 及以上 | `/f ban <玩家名>` |
| 解封玩家 | 解除目标玩家的封禁 | Admin 及以上 | `/f unban <玩家名>` |
| 转让所有权 | 将阵营主人转让给目标玩家 | 仅 Owner | `/f transferowner <玩家名>` |

::: danger 转让所有权不可逆
[转让所有权] 会把 Owner 移交给他人的输入框目标玩家，操作后你自己将降为普通成员，**无法自行撤销**，请务必确认。
:::

### 职位管理

Owner / Admin 可用。通过输入框填写职位名（仅英文字母）、拖动滑块选择优先级（1~1000）、填写目标玩家名来操作：

| 按钮 | 作用 | 等效指令 |
| --- | --- | --- |
| 查看职位列表 | 查看全部职位与权限配置 | `/f rank` |
| 创建职位 | 以输入框的职位名与优先级创建职位 | `/f rank create <职位名> <优先级>` |
| 任命职位 | 将输入框玩家的职位设为指定职位 | `/f rank assign <玩家名> <职位名>` |
| 删除职位 | 删除指定职位，该职位成员会回落到默认职位 | `/f rank delete <职位名>` |

优先级参考：成员 1 / 长老 10 / 管理 100 / Owner 1000——优先级越高，职位越高。

### 领地管理

已加入阵营后可用。**站在目标区块上**操作；半径操作以脚下区块为中心，通过滑块选择 1~5 格：

| 按钮 | 作用 | 等效指令 |
| --- | --- | --- |
| 认领当前区块 | 认领脚下区块为阵营领地 | `/f claim` |
| 半径认领 | 以脚下为中心认领指定半径（消耗更多点数） | `/f claim <半径1-5>` |
| 放弃当前区块 | 放弃脚下区块 | `/f unclaim` |
| 半径放弃 | 以脚下为中心放弃指定半径 | `/f unclaim <半径1-5>` |
| 查看区块地图 | 在聊天栏显示周围区块的领地归属 | `/f map` |
| 点数查询 | 查看点数、积累速度与维护消耗 | `/f power` |
| 荒野传送 | 传送到无主荒野（原地站立 5 秒后生效，冷却 30 秒） | `/f wilderness` |

::: warning 领地维护消耗
每一块领地都会持续消耗阵营点数（维护费用）。认领前请留意阵营点数是否充足，详情可用 [点数查询] 查看。
:::

### 阵营基地

已加入阵营后可用：

| 按钮 | 作用 | 所需权限 | 等效指令 |
| --- | --- | --- | --- |
| 传送到基地 | 传送至阵营公共基地 | teleport-home | `/f home` |
| 设置基地位置 | 将当前所在位置设为阵营基地 | set-home（默认 Admin 及以上） | `/f sethome` |

### 外交关系

Owner / Admin 可用。在输入框填写对方阵营名后执行操作：

| 按钮 | 作用 | 等效指令 |
| --- | --- | --- |
| 查看盟友 | 查看当前盟友阵营 | `/f allies` |
| 查看敌对 | 查看当前敌对阵营 | `/f enemies` |
| 申请结盟 | 向目标阵营发起结盟请求 | `/f ally <阵营名>` |
| 接受结盟 | 接受目标阵营的结盟请求 | `/f allyaccept <阵营名>` |
| 宣战 | 对目标阵营宣战 | `/f war <阵营名>` |

::: danger 宣战需谨慎
宣战后**双方领地均可被围攻**。请与管理层商议后再执行，避免阵营领地与资源陷入险境。
:::

## 方式二：直接输入指令

所有菜单功能都有对应指令。主指令 `/factions` 可简写为 `/f`（下表统一用 `/f` 演示），直接在聊天栏输入即可。

### 信息查询

| 指令 | 作用 |
| --- | --- |
| `/f list` | 查看服务器阵营列表 |
| `/f members` | 查看本阵营成员列表 |
| `/f rank` | 查看本阵营职位列表 |
| `/f power` | 查看阵营点数与积累详情 |
| `/f map` | 查看周围区块的领地归属地图 |
| `/f invites` | 查看收到的加入邀请 |
| `/f allies` | 查看盟友阵营 |
| `/f enemies` | 查看敌对阵营 |

### 加入与创建

| 指令 | 作用 |
| --- | --- |
| `/f create <阵营名>` | 创建阵营（任意字符），你成为 Owner |
| `/f join <阵营名>` | 加入阵营（公开阵营直接加入，仅邀请阵营需先获邀） |
| `/f inviteaccept <阵营名>` | 接受该阵营的加入邀请 |
| `/f invitediscard <阵营名>` | 拒绝该阵营的加入邀请 |

### 成员管理

| 指令 | 作用 | 权限要求 |
| --- | --- | --- |
| `/f invite <玩家名>` | 邀请玩家加入 | 成员 |
| `/f kick <玩家名>` | 踢出成员 | Admin 及以上 |
| `/f ban <玩家名>` | 封禁玩家 | Admin 及以上 |
| `/f unban <玩家名>` | 解封玩家 | Admin 及以上 |
| `/f transferowner <玩家名>` | 转让阵营所有权 | 仅 Owner，不可逆 |

### 职位管理

| 指令 | 作用 |
| --- | --- |
| `/f rank create <职位名> <优先级>` | 创建职位（仅英文字母，优先级 1~1000） |
| `/f rank assign <玩家名> <职位名>` | 任命玩家为指定职位 |
| `/f rank delete <职位名>` | 删除职位，其成员回落默认职位 |

### 领地与传送

| 指令 | 作用 |
| --- | --- |
| `/f claim` | 认领当前区块 |
| `/f claim <半径1-5>` | 以脚下为中心半径认领（消耗更多点数） |
| `/f unclaim` | 放弃当前区块 |
| `/f unclaim <半径1-5>` | 以脚下为中心半径放弃 |
| `/f home` | 传送到阵营基地 |
| `/f sethome` | 将当前位置设为阵营基地（默认 Admin 及以上） |
| `/f wilderness` | 荒野传送（站立 5 秒生效，冷却 30 秒） |

### 外交

| 指令 | 作用 | 权限要求 |
| --- | --- | --- |
| `/f ally <阵营名>` | 申请结盟 | Owner / Admin |
| `/f allyaccept <阵营名>` | 接受结盟请求 | Owner / Admin |
| `/f war <阵营名>` | 宣战（双方领地可被围攻） | Owner / Admin |

## 注意事项小结

- 职位名**仅支持英文字母**；阵营名支持任意字符（含中文），最长 36 字符。
- 菜单的输入框内容在点击按钮时生效——先填内容，再点按钮。
- 每块领地都会消耗阵营点数做维护，扩地前先 `/f power` 查看点数。
- 转让所有权、宣战都是高风险操作，前者不可逆，后者会开放双方领地被围攻。
- 玩法处于内测阶段，规则与数值可能调整，以服务器内实际为准。
