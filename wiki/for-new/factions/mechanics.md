# 阵营对抗机制

本页整理官方设定稿中的对抗机制设计。玩法将随内测逐步实装，实际数值与规则以服务器内为准。

## 机制对照表

两大阵营的玩法围绕**同一套资源、两种用法**镜像展开：

| 机制 | 黎明誓约 | 暮夜同盟 |
| --- | --- | --- |
| **昼夜增益** | 白天：防御 / 恢复（"黎明庇护"） | 夜晚：速度 / 夜视 / 攻击（"长夜同行"） |
| **核心资源** | 黎明碎片 | 暮影结晶 |
| **主城风格** | 城堡、灯塔、农田 | 营地、地堡、黑市 |
| **阵营积分** | 建设、守护、护送 | 击杀、掠夺、占点 |
| **世界事件** | 点燃曙光灯塔 | 举行永夜仪式 |
| **死亡播报** | "黎明誓约的 XX 净化了暮夜同盟的 YY" | "暮夜同盟的 XX 将黎明誓约的 YY 拖入长夜" |

## 设计意图

这套对照表是刻意做成**同一套资源、两种用法**：

- **昼夜增益**：同一段时间，双方各有主场——没有哪个阵营能全天候压制对方。
- **核心资源**：黎明碎片要靠建设与守护产出，暮影结晶要靠击杀与掠夺产出——**资源来源直接决定玩法风格**。
- **阵营积分**：黎明方"慢但稳"，暮夜方"快但险"，积分曲线一个爬坡一个锯齿。
- **世界事件**：灯塔会被熄灭，仪式会被打断——**任何一方的胜利都不是永久的**。

> 两个阵营的胜负不是靠"谁更正义"，而是靠"谁先把世界改成自己想要的样子"。谁也没法彻底消灭对方，这场仗的设计目标就是**长期拉锯**，而不是一次性决战。

## 世界事件

### 点燃曙光灯塔（黎明誓约）

黎明方收集**黎明碎片**，点亮三座**曙光灯塔**：灯塔每点亮一座，黎明方的安全区边界就往外推一圈；最终目标是驱散长夜、净化乱世生物、重建安全区。而暮夜方则会伺机摧毁灯塔，把黎明打回长夜。

### 永夜仪式（暮夜同盟）

暮夜方举行**永夜仪式**，争夺**星穹核心**、维持永夜，建立自由黑市与无人管得着的领地；黎明方则会集结打断仪式，夺回昼夜的主动权。

## 阵营专属死亡播报

接入 CustomDeathMessages 后，阵营间的击杀将触发专属播报文案（效果示例）：

- 黎明击杀暮夜：`黎明誓约的 <玩家A> 净化了暮夜同盟的 <玩家B>`
- 暮夜击杀黎明：`暮夜同盟的 <玩家A> 将黎明誓约的 <玩家B> 拖入长夜`

::: warning 实装说明
死亡播报、卷轴奖励、昼夜增益等机制将随内测逐步实装，最终文案与数值以服务器内为准。
:::

## 与现有系统的接入

| 现有系统 | 接入方式 |
| --- | --- |
| **CustomDeathMessages** | 阵营专属死亡播报，按击杀者 / 被击杀者的阵营动态替换文案 |
| **卷轴系统** | 阵营奖励（护身卷轴、回城卷轴、回溯卷轴），按阵营积分或世界事件发放 |
| **登录服** | 选阵营界面承载两阵营招募文案与阵营标识 |
| **服务器架构** | 阵营归属跟随玩家数据，跨服互跳时保持阵营前缀与增益一致 |

关于服务器技术栈与官网系统的整体架构，见[服务器架构总览](/develop/architecture/)。
