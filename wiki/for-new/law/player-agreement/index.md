# 服务器游玩规则与惩罚条例
> 修订日期：**2025/10/11**   修订人：`@qwert` `@邓` `@Floyd`

欢迎来到我们的服务器！为了保障所有玩家的游戏体验，请务必遵守以下规则。所有处罚将由管理团队公平执行，并保留最终解释权。
## 一、 严重违规行为（零容忍，一经发现立即永久封禁）

::: danger 警告
这些行为会直接破坏服务器根基和玩家体验，没有任何商量余地。
:::

1. 使用任何形式的外挂、作弊客户端、BUG牟利
   - 包括但不限于： 透视、飞行、杀戮光环、自动挖掘、无限复制、利用严重BUG刷取物品。
   - 惩罚： 永久封禁所有相关账户，并清空其所有物资。欢迎玩家通过私聊管理举报。
2. 恶意破坏、 griefing
   - 定义： 未经允许，故意破坏其他玩家的建筑、地形、红石装置；使用 lava、TNT、水流等故意制造破坏。
   - 惩罚： 首次即永久封禁。并尽可能由管理员回滚破坏。
3. 欺诈、盗窃
   - 定义： 通过谎言骗取他人贵重物品；未经允许拿走他人箱子/漏斗中的物品。
   - 惩罚： 永久封禁。并尽可能归还被盗物品。
4. 发表任何形式的仇恨、歧视言论
   - 包括但不限于： 涉及种族、地域、性别、性取向、人身攻击的极端辱骂。
   - 惩罚： 永久封禁。

## 二、 一般违规行为（根据情节严重程度进行阶梯式处罚）

::: warning 注意
这些行为会影响社区和谐和游戏秩序。
:::

1. 垃圾信息、刷屏、广告
   - 定义： 短时间内重复发送相同内容；发送与服务器无关的第三方广告。
   - 惩罚：
     - 第一次：禁言1小时 + 警告。
     - 第二次：禁言24小时。
     - 第三次：永久禁言。
2. 占用公共区域、违规建筑
   - 定义： 在主城/出生点等公共区域违规建造；建造丑陋、无意义的“柱子”；建筑严重影响他人视野或服务器性能。
   - 惩罚：
     - 管理员会通知其限期拆除。
     - 逾期未处理，管理员将直接清除违规建筑，并不予补偿。
     - 屡教不改者，可能面临短期封禁（1-7天）。
3. 滥用游戏机制
   - 定义： 建造大量高频红石导致服务器卡顿；恶意繁殖大量生物（如猫、鱼）导致卡顿；利用漏洞进行不影响平衡的牟利。
   - 惩罚：
     - 第一次：警告并清除相关装置/生物。
     - 第二次：短期封禁（1-3天）。
     - 情节严重或屡教不改：永久封禁。
4. 不当言论（轻度）、争吵
   - 定义： 在公屏发生持续争吵、阴阳怪气、人身攻击（轻度）。
   - 惩罚：
     - 管理员介入调解并口头警告。
     - 若不停止，涉事双方均被禁言1-12小时以冷静。
     - 故意挑起事端者，可能面临短期封禁（1-3天）。

## 三、 玩家纠纷与财产保护

1. “熊孩子”风险自担：
   - 服务器强烈建议所有玩家保护自己的土地和箱子。
   - 如果因自身导致物品被偷或建筑被破坏，管理团队原则上不予处理。请务必保护好自己的财产！
2. 玩家交易：
   - 玩家之间的所有交易（以物易物、游戏币交易）请自行甄别风险。
   - 建议在交易时录制视频或截图作为证据。如发生欺诈行为，请立即带证据私聊管理举报。

## 四、 处罚申诉流程

如果你认为管理员的处罚有误或不公，你可以通过以下途径申诉：

1. 保持冷静，通过 QQ私聊 联系 @邓 或 [@你的QQ昵称]。
2. 清晰地陈述你的游戏ID、被处罚的原因、时间，以及你认为处罚不当的理由。
3. 管理团队会重新调查（如查日志、询问证人等）并在24小时内给你最终答复。
