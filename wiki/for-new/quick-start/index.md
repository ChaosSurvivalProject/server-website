# 进服指南：Java 与基岩双端并列步骤

星穹旅驿是《我的世界》Java / 基岩双端互通的阵营生存服。本页面是纯文字版进服总览，
无 JavaScript 也能完整阅读；详细图解见下方分端指南。

**服务器地址：`serverone.codeyun.com:12000`**

- Java 版：在「添加服务器」中填写完整地址 `serverone.codeyun.com:12000`。
- 基岩版：服务器地址填 `serverone.codeyun.com`，端口填 `12000`。

服务器地址的权威数据源是官网后端的监控接口，官网首页与状态卡片按接口结果实时展示；
本页作为文档快照，便于搜索引擎收录与离线查阅。

## 支持版本速览

- Java 版：`1.21.1 ~ 1.21.11`，推荐 `1.21.11`（ViaVersion / ViaBackwards 兼容多版本）。
- 基岩版：`1.21.x` 最新正式版（Geyser + Floodgate 与 Java 版同服互通）。

完整说明见[版本与客户端支持范围](/for-new/versions/)。

## Java 版加入步骤

1. 下载并安装 Java 版客户端。正版用户可从 [Minecraft 官网](https://www.minecraft.net/)获取启动器，
   离线登录用户可使用 [PCL2 启动器](https://afdian.net/item?plan_id=86122222221212)。
2. 在启动器中选择 `1.21.11`（或 `1.21.1 ~ 1.21.11` 内的版本）并安装。
3. 启动游戏，进入「多人游戏」→「添加服务器」。
4. 服务器地址填写 `serverone.codeyun.com:12000`，点击「完成」。
5. 选中服务器并点击「加入服务器」。
6. 首次进入按提示注册：`/register 你的密码 重复你的密码`；老玩家登录：`/login 你的密码`。
7. 在登录服选择阵营：**黎明誓约** 或 **暮夜同盟**，冒险开始。

带截图的逐步教程见 [Java 版玩家加入服务器指南](/for-new/join-server/for-java-client/)。

## 基岩版加入步骤

1. 从[基岩版客户端下载页面](https://xz.klpz.net/)下载并安装最新正式版。
2. 注册并登录微软账号（可参考[视频教程](https://www.bilibili.com/video/BV13S4y177Fc)）。
3. 进入游戏 →「服务器」→「添加服务器」。
4. 服务器名称可自定义；服务器地址填 `serverone.codeyun.com`，端口填 `12000`。
5. 添加后点击连接，注册 `/register <密码> <重复密码>` 或登录 `/login <密码>`。

基岩版通过 Geyser 与 Java 版互通，部分 Java 版特性可能存在差异，遇到问题可向技术组反馈。
更多细节见 [基岩版玩家加入服务器指南](/for-new/join-server/for-bedrock-client/)。

## 阵营与规则

服务器核心玩法为两大阵营对抗：

- **黎明誓约**：以光为界，守土求生；火种不熄，黎明必至。
- **暮夜同盟**：长夜将至，强者为尊；既然乱世，就燃得更旺。
