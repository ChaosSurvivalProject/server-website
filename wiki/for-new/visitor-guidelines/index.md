# 游玩须知
本文档为游玩服务器前必看。

## 服务器简介

星穹旅驿是一个以**阵营对抗**为核心的 Minecraft 乱世生存服务器。大崩裂之后，星穹界长夜与残阳交替，**黎明誓约**与**暮夜同盟**两大阵营对同一片世界得出了完全相反的答案——你的立场，决定这个世界的样子。

- 服务器核心：Purpur 1.21.11（Minecraft 1.21.11）
- 跨版本游玩：ViaVersion / ViaBackwards 支持多版本 Java 版客户端
- 跨平台联机：Geyser 支持基岩版（移动端）加入，与 Java 版玩家同服游玩
- 阵营玩法：黎明誓约 vs 暮夜同盟，详见[阵营玩法总览](/for-new/factions/)
